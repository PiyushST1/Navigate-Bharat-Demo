Auto-archive rule

How it works
  1. Every PSA has a valid-till date set by CBFC.
  2. From the day after that date the PSA is shown as Archived on the public portal and cannot be scheduled.
  3. "Run archival now" also updates the stored record and keeps it in the library for audit.
